## 订阅方式

### Apple 日历 / iPhone / Mac

复制以下任一链接，添加到日历订阅：

**GitHub 原始地址：**
```
https://raw.githubusercontent.com/CY-Christin/100days-calendar/main/100days.ics
```

**jsDelivr CDN（推荐，国内更快）：**
```
https://cdn.jsdelivr.net/gh/CY-Christin/100days-calendar/100days.ics
```

#### iPhone / iPad 添加方法
1. 打开「日历」App
2. 点击底部「日历」→ 左下角「添加日历」→「添加订阅日历」
3. 粘贴上面的链接 → 订阅

#### Mac 添加方法
1. 打开「日历」App
2. 菜单栏「文件」→「新建日历订阅」
3. 粘贴链接 → 订阅

### Google Calendar
1. 打开 Google 日历网页版
2. 左侧「其他日历」旁边的「+」→「通过网址添加」
3. 粘贴上面的链接
